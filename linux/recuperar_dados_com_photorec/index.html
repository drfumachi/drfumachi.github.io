Recuperar dados com photorec

Já passou por alguma situação que os dados simplesmente sumiram do pendrive? Algumas vezes isso pode acontecer por algum tipo de problema lógico no PC ou por formato de arquivos...

Nesse tutorial tentaremos recuperar os dados para outro lugar do PC.

Primeiro deve-se verificar se o photorec está instalado no sistema:

sudo apt update
sudo apt install testdisk

Insira o pendrive (flashdrive) na porta USB do computador e, no terminal, faça:

lsblk

a resposta pode ser algo assim:

sda 931.5G
├─sda1 512M
└─sda2 931G
sdb 14.9G <-- Esse é o pendrive
└─sdb1 14.9G

Anote o caminho do pendrive e faça:

sudo photorec

Um menu será aberto. Use as setas e teclas para selecionar a PARTIÇÃO ou o disco todo (WHOLE DISK), selecione o tipo de sistema de arquivos. Escolha o modo de leitura de arquivos (FREE: tenta recuperar arquivos deletados. WHOLE: escaneia tudo). Selecione o local de salvamento dos arquivos que serão recuperados (NÃO use o próprio pendrive)
