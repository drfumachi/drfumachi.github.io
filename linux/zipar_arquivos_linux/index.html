Zipar arquivos no GNU/Linux

Atualiza a lista de pacotes

sudo apt update

Instala o zip e unzip

sudo apt install zip unzip

Cria um arquivo ZIP com um único arquivo

zip arquivo.zip arquivo.txt

Cria um ZIP com múltiplos arquivos

zip arquivos.zip arquivo1.txt arquivo2.txt arquivo3.txt

Cria um ZIP contendo toda a pasta e seus subarquivos

zip -r pasta.zip minha_pasta/

Extrai os arquivos de um ZIP

unzip arquivo.zip
